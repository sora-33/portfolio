campass

開発中の個人開発プロジェクト

campass は、無料キャンプ場・野営地を探すための Web アプリです。 地図と位置情報を軸に、まだ広く知られていないスポットも見つけやすくすることを目指しています。

公開状況

現在は個人開発として継続的に改善を進めています。 公開版は https://campass-jp.vercel.app/ から確認できます。 ソースコードと設計資料は GitHub の Private リポジトリで管理しています。

担当

企画 / 要件整理 / 画面設計 / 実装 / テスト / GitHub によるタスク管理

主な機能（予定）

地域・条件によるキャンプ場検索、野営地の登録と閲覧、レビュー・写真投稿、 近隣施設の情報表示、管理者向け管理機能を予定しています。

技術スタック

Next.js / TypeScript / Prisma / PostgreSQL / Docker / GitHub Actions
